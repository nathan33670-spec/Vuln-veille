# Data files

- `common-passwords.txt`: the 10,000 most common passwords, lower-cased and de-duplicated, from
  [SecLists](https://github.com/danielmiessler/SecLists) (`Passwords/Common-Credentials/10k-most-common.txt`),
  MIT License, © Daniel Miessler and contributors. Used offline to refuse weak passwords
  (SECURITY.md §4.1): no password is ever sent to a third-party service.
